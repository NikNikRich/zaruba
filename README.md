## Решения, которые уже зафиксированы

- **Сайт делает фанат**, а не организатор: не продаём билеты, не принимаем
  деньги, не выглядим официальными, домен — без слова «заруба».
- **Первым делаем информационный блок** (`06`), интерактив (`05`) — поверх
  готовых данных.
- Стек — как в прежнем проекте: **FastAPI + Jinja2 + HTMX**, PostgreSQL,
  Alembic, pytest, ruff. Без SPA, без JS-логина, инфо-страницы работают без JS.
- Пакет будет называться `src/zaruba/` (отдельный, не внутри чужого `src/app`).
- Каждый факт на сайте — со **статусом источника** (`подтверждено` /
  `не подтверждено` / `устарело`); для несовершеннолетних без согласия —
  инициалы, без фото, `noindex`.

## Запуск сайта

```powershell
cd C:\well-service-platform\Zaruba
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m uvicorn zaruba.main:app --reload --port 8000
```

Страницы: `/` (главная), `/event` (о событии и хронология), `/schedule`
(расписание, `?day=1`), `/performances` (каталог с фильтрами `?day=&style=&age=&format=&studio=&video=1`),
`/performances/{slug}` (карточка выступления), `/participants/{slug}` (карточка участника),
`/venue` (площадка), `/healthz` (состояние). Шаблоны — серверный рендер: все факты видны при
выключенном JS, неизвестный адрес отдаёт HTML-страницу 404 с выходами.

```powershell
.\.venv\Scripts\python.exe -m pytest -q             # тесты
.\.venv\Scripts\python.exe -m ruff check src tests   # линт
.\.venv\Scripts\python.exe -m zaruba.content check   # проверить YAML выпусков
.\.venv\Scripts\python.exe -m zaruba.content import content\editions\2025.yaml
```

Правила контента (проверяются тестами, а не «на глаз»):

- любое поле сверх модели — ошибка, опечатка в YAML не теряется молча;
- блок обязан ссылаться на существующие номинации того же дня;
- выступление ссылается на существующую номинацию, участников и дату выпуска;
- у несовершеннолетнего без согласия публичное имя — только инициалы;
- демонстрационные строки помечены `demo: true` и показываются как «пример».


## Презентация проекта

[`presentation/index.html`](presentation/index.html) — один автономный файл
(HTML + CSS + ~50 строк JS, без интернета, шрифтов и библиотек): 15 слайдов,
внутри — не картинки, а живые макеты страниц будущего сайта.

| Слайды | О чём |
|---|---|
| 01–03 | титул, проблема, публично подтверждённые факты |
| 04–05 | три ядра аудитории, правило «20 секунд / 3 тапа», чего на сайте не будет |
| 06–11 | макеты: главная, расписание (+ мобильная версия), выступления и карточка выступления, приватность участников, площадка, рейтинги |
| 12–15 | статусы источников и пустые состояния, архитектура и стек, план M0–M6, KPI и следующий шаг |

Управление: `←` `→` / пробел — листать, `F` — полный экран, `P` — печать в PDF
(A4 landscape, по слайду на страницу). Прямой переход на слайд — `#s07`.

```powershell

```

## Чего не хватает (блокеры данных)

Все пункты — `ГИПОТЕЗА`, пока не подтверждены организаторами:

- «Положение» чемпионата: номинации, возрастные группы, критерии судейства.
- Взносы участников, цены и правила возврата билетов.
- Статистика прошлых лет: число участников, городов, зрителей.
- Даты следующего выпуска и права на бренд/домен.
- VK и Telegram недоступны боту — публичные посты собираются вручную.

Правило проекта: неподтверждённый факт **не выдумывается** — он либо не
показывается, либо показывается с явной пометкой и ссылкой на первоисточник.
